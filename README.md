# 1. Introdução

**Contexto:** O Hospital Amaral Carvalho possui um robô chamado Elo, que foi um investimento do Hospital, porém não está sendo utilizado 100% do tempo.

**Justificativa:** Sabendo disso, iremos criar um site que irá acolher as crianças que estão em tratamento no hospital e que irá dar mais utilidade para o robô.

## • Objetivos

Desenvolver um site no qual serão adicionados os jogos já existentes da empresa e adicionar jogos criados por nós ou possivelmente por outras pessoas.

## • Metodologia

- **Modelo:** incremental
- **Com o quê:** HTML, CSS, JS + Trello (organização)
- **Onde:** ambiente web
- **Quando:** durante o semestre
- **Quem:** crianças

# 2. Requisitos

## • Requisitos funcionais

RF01 – Cadastro e login de usuários (Nome, E-mail, Senha, Confirmação).  
RF02 – Navegação entre páginas (Início, Sobre, Jogos, Contato, Login/Cadastro, Equipe).  
RF03 – Administradores publicam/removem jogos (Nome, Categoria, Descrição, Capa, Arquivo/link).  
RF04 – Vitrine dos jogos (Nome, Capa, Categoria, Descrição, Avaliação média).  
RF05 – Visualização de detalhes do jogo.  
RF06 – Execução do jogo direto no navegador (botão "Jogar").  
RF07 – Envio de feedbacks.  
RF08 – Avaliação por estrelas (1 a 5) e comentário.  
RF09 – Pesquisa por nome do jogo.  
RF10 – Página de Contato com formulário e redes sociais.  
RF11 – Visualização da equipe do projeto.  
RF12 – Exibição de jogos em destaque.  
RF13 – Filtragem (categoria, avaliação, ordem alfabética).  
RF14 – Coleta/armazenamento de dados pelos jogos.

## • Requisitos não funcionais

RNF01 – Interface simples e intuitiva.  
RNF02 – Resposta de até 3 s.  
RNF03 – Responsivo.  
RNF04 – Navegação fluida.  
RNF05 – Organização via Trello.  
RNF06 – Desenvolvimento incremental.  
RNF07 – Evitar falhas nos jogos.  
RNF08 – Funcionamento contínuo.  
RNF09 – HTML, CSS e JavaScript.  
RNF10 – Sem instalação (web).  
RNF11 – Código comentado.  
RNF12 – Compatível com Chrome, Firefox, Edge.  
RNF13 – Desktop e mobile.

# 3. Estudo de Viabilidade

**Técnica:** 100% web; desenvolvimento nos notebooks pessoais + infra Fatec + Trello.  
**Operacional:** modelo incremental, divisão clara, código comentado.  
**Mercado:** público-alvo infantil hospitalar; diferencial é o canal oficial do hospital.  
**Financeira:** custo zero (open-source + GitHub Pages); retorno social.

# 4. Regras de negócio (Modelo Canvas)

![Modelo Canvas](https://github.com/user-attachments/assets/d7391d22-ccb7-4bb8-88d9-c944ea8c7b8d)

- **Proposta de valor:** acolhimento + portfólio do hospital/robô Elo.
- **Parcerias:** Fatec, Hospital Amaral Carvalho.
- **Atividades-chave:** entender o problema, levantar requisitos, prototipar, desenvolver.

- **Relacionamento:** feedback integrado.

- **Receitas:** nenhuma no momento.
